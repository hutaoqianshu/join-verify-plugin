# join-verify-plugin

Yunzai-Bot 入群审核插件：手机号 + 游戏 ID 双重校验，配合红名单、限时黑名单、退群管控与群管清退，把入群口子守稳。

## 特性

- **多种审核模式**：拒绝 / 手机号验证 / 全部验证（手机号 + ID），可按群独立配置
- **手机号校验**：格式校验 + 虚拟运营商识别 + 归属地查询，支持多 API 接口自动择优与巡检
- **黑白名单**：永久红名单、限时黑名单（次数阈值触发）
- **退群管控**：标记退群用户，二次入群可设「拒绝」或「正常验证」
- **导流引流**：群满时自动引导至指定群，拒绝文案中的群号可动态修改
- **群管清退**：跨群检索指定 QQ，批量撤回其发言并踢出
- **审核通知**：通过/拒绝/异常均推送至指定通知群
- **API 异常兜底**：接口全不可用时转人工审核，不误拒正常用户

## 安装

1. 将本插件放入 Yunzai-Bot 的 `plugins/` 目录

```bash
cd Yunzai-Bot/plugins
git clone https://github.com/<your-name>/join-verify-plugin.git
```

2. 安装依赖

```bash
cd join-verify-plugin
pnpm install
```

3. 重启 Bot

```bash
# 在 Yunzai 根目录
pnpm start
```

首次启动会自动创建 `config/config/` 与 `data/` 目录及所需的空数据文件，无需手工准备。

## 配置

配置文件：`config/config/config.yaml`（首次启动从 `default_config/` 自动复制）

```yaml
# 触发自动拉黑的申请次数阈值
blacklistThreshold: 10
# 限时黑名单时长（秒）
blacklistDuration: 3600
# 是否启用自动拉黑
blacklistEnabled: true
# API 巡检间隔（秒）
apiCheckInterval: 600
# 审核通知推送群号，留空则不推送
notificationGroup: ""
# 虚拟运营商号段前缀，留空则只依赖 API 判定
virtualNumberPrefix:
  - "170"
  - "171"
  - "165"
# 导流配置（首次使用请通过 #设置导流x群群号+qq群号 命令设置）
diversionEnabled: true
diversionIndex: ""
diversionGroupId: ""
diversionText: "本群已满，请加{index}群{groupId}"
# 退群策略的额外白名单管理员 QQ，留空则仅主人可操作
leaveUserAdminQQ: ""
```

> `diversionText` 支持 `{index}` 与 `{groupId}` 占位符，一般无需改动。

## 命令

所有命令**仅限 Bot 主人**使用。

### 群规则

| 命令 | 说明 |
|---|---|
| `#开启入群审核` | 当前群开启全部验证（手机号 + ID） |
| `#开启手机号验证` | 当前群仅验证手机号 |
| `#关闭入群审核` | 当前群关闭审核 |
| `#设置入群规则 [群号] [拒绝/手机号验证/全部验证]` | 设置指定群规则 |
| `#设置导流[x]群群号[群号]` | 设置导流目标，如 `#设置导流9群群号12382479` |

### 黑白名单

| 命令 | 说明 |
|---|---|
| `#新增红用户 [QQ/@用户]` | 加入永久黑名单 |
| `#删除红用户 [QQ/@用户]` | 移出永久黑名单 |
| `#新增黑名单 [QQ/@用户]` | 加入当前群限时黑名单 |
| `#删除黑名单 [QQ/@用户]` | 移出当前群限时黑名单 |
| `#设置黑名单阈值 [数字]` | 设置触发拉黑的申请次数 |
| `#设置黑名单时间 [秒]` | 设置拉黑时长 |
| `#拉黑开启` / `#拉黑关闭` | 开关自动拉黑 |

### 退群用户

| 命令 | 说明 |
|---|---|
| `#查看退群用户 [页码]` | 分页查看退群用户列表 |
| `#设置退群用户策略 [QQ] [验证/拒绝]` | 设置二次入群策略 |
| `#移除退群用户 [QQ/@用户]` | 移除退群标记 |

### 群管理与清退

| 命令 | 说明 |
|---|---|
| `#获取需管理群` | 获取已配置规则的群列表（前置命令） |
| `#获取所有群员` | 遍历管理群抓取成员列表 |
| `#联动清退 [QQ]` | 检索该 QQ 在所有管理群的位置，等待确认 |
| `#确认清退` | 执行撤消息 + 踢出 |
| `#取消清退` | 取消本次清退 |
| `#测试检索清退群 [QQ]` | 仅检索，不执行 |
| `#测试撤回消息 [QQ] [秒]` | 仅统计可撤回消息数，不执行 |

### API 管理

| 命令 | 说明 |
|---|---|
| `#新增查询api [地址]` | 添加手机号查询接口，地址中用 `{phone}` 占位 |
| `#删除查询api [地址]` | 删除接口 |
| `#查询API列表` | 查看所有接口状态与延迟 |
| `#测试api` | 测试所有接口可用性 |

### 查询与测试

| 命令 | 说明 |
|---|---|
| `#查询用户 [QQ/@用户]` | 查询绑定、黑名单、退群状态 |
| `#入群自动化统计` | 查看审核统计 |
| `#入群验证插件设置` | 查看当前配置 |
| `#入群验证菜单` | 显示完整菜单 |
| `#设置通知群` | 将当前群设为审核通知群 |
| `#测试验证 [内容] [模式]` | 测试校验流程，不实际处理 |
| `#QQ接口测试 [群号]` | 检测协议端支持的接口 |

## 入群申请怎么填

手机号验证模式下，申请人需在**入群验证消息**中连续填写手机号与 8 位游戏 ID：

```
1380013800012345678
```

全部验证模式下会额外校验 ID 为 8 位数字且手机号非虚拟运营商。

## 数据说明

| 文件 | 内容 |
|---|---|
| `bindings.json` | 手机号 ↔ QQ 绑定 |
| `redUsers.json` | 永久黑名单 |

| `applyCounts.json` | 申请次数计数 |
| `groupRules.json` | 各群审核规则 |
| `statistics.json` | 审核统计 |
| `auditLogs.json` | 审核日志（超 3000 条自动归档） |
| `managedGroups.json` | 需管理群列表 |
| `groupMembers.json` | 群成员快照 |
| `leaveUsers.json` | 退群用户 |
| `apiList.json` | 查询接口列表 |
| `pendingCleanup.json` | 待确认的清退操作 |

## 注意事项

- **协议端**：推荐 NapCat，需支持 `set_group_add_request`（入群申请处理）
- **通知群发不出**：若 notificationGroup 设置后收不到消息，多为协议端网络异常，检查 NapCat 日志
- **清退不可逆**：`#确认清退` 会实际踢人，建议先用 `#测试检索清退群` 验证名单
- **API 依赖**：手机号校验依赖第三方接口，接口不稳定时会自动转人工审核而非误拒
